# Lanarve SEO audit — 22 October 2026

Scope: repository at `ac9b6f2`, English B2B home-fragrance site; implementation is on `feat/seo-b2b-audit`. No production deployment, DNS change or merge is authorized.

## Repository and delivery architecture

- Python generators under `scripts/` create static HTML from six product JSON catalogues, 39 fragrance profiles and stable SKU/URL mappings. There are 288 current product detail pages; no SPA conversion or new product URL scheme is needed.
- `scripts/version-site-assets.py` rebuilds catalogues/details/navigation and emits content-hashed CSS/JS. `scripts/prepare-pages.py` validates and stages `_site/` using Python's standard library.
- `.github/workflows/deploy-pages.yml` builds and deploys **only main** using GitHub Actions/Pages. Pushing the SEO feature branch does not publish the website. Actual HTTP redirects, HTTPS enforcement and custom-domain settings are configured in GitHub Pages/DNS, not by `.htaccess` or `_redirects` files.
- Existing root HTML is committed output; all changes must survive generation. Raw source product images, catalogue identity keys, default fragrance assignments, product URLs and paired-view order must remain stable.

## Live checks and access limits

Both apex and www were probed with HTTP/HTTPS, plus contact, robots, sitemap, a missing URL and the historical GitHub Pages URL. This execution environment's proxy returns HTTP CONNECT 403 / blocks outbound access. **This is not evidence that Lanarve returns 403.** See `live-probes-2026-10-22.json` for exact commands' responses. Prior deployment records identify www.lanarve.com as the Pages custom-domain destination, but live TLS/redirect behavior cannot be verified here.

Before merging, an owner/reviewer must verify from an unrestricted network:

1. HTTPS www homepage/category/product return 200; TLS certificate is valid.
2. HTTP and non-www converge to the selected `https://www.lanarve.com` host without redirect chains. Check Pages “Enforce HTTPS”, custom domain and DNS; no DNS/account settings are changed in this PR.
3. An arbitrary missing URL really returns 404, not a soft-404 200; robots and sitemap return 200 and the expected body.
4. The deployed HTML includes the new static product content and canonical tags. Feature-branch checks cannot certify a not-yet-deployed version.

## Keyword strategy

All phrases are **intent hypotheses**, based on the supplied product/service offering. No keyword-tool data, search-volume or difficulty numbers were available. See `keyword-map.csv`. Use buyer qualification rather than consumer price/discount intent. Seasonal and scent pages support discovery and link to actual product designs; private-label service owns the broad customization intent.
